개인정보처리방침 (Privacy Policy)

시행일: 2026-11-23

1. 사용하는 Google 데이터

KingJo Upload는 YouTube Data API를 통해 채널 운영자 본인의 YouTube 계정에만 접근합니다. 사용하는 기능은 영상·썸네일·자막 업로드, 영상 정보(제목·설명·예약 시각) 수정, 재생목록 관리, 본인 채널 댓글 확인과 답글 작성입니다.

2. 저장과 공유

로그인 정보(토큰)는 운영자 본인의 컴퓨터에만 저장됩니다. Google 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고에 사용하지 않습니다.

3. 다른 사용자

이 도구는 운영자 본인만 사용합니다. 다른 사람의 Google 계정 데이터를 요청하거나 수집하지 않습니다.

4. 접근 해제

Google 계정의 보안 설정(서드 파티 액세스)에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.

KingJo Upload's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to upload and manage videos on the operator's own YouTube channel and is never sold or shared.
